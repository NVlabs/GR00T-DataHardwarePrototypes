# Security Policy

## Reporting a Vulnerability

To report a potential security vulnerability in GR00T Data Hardware Prototypes software, firmware, or repository tooling, please follow the instructions on NVIDIA's [Report a Security Vulnerability](https://www.nvidia.com/en-us/security/report-vulnerability/) page.

You can submit a report through the vulnerability disclosure program linked on that page or contact [NVIDIA PSIRT](mailto:psirt@nvidia.com). For email reports, follow the PGP encryption instructions on the reporting page.

Please do not disclose potential vulnerabilities through public GitHub issues, discussions, or pull requests. Use the private reporting channels above.

## Information to Include

To help investigate the issue, include:

- The repository name, affected version or commit SHA, and affected files or components.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue and a minimal proof of concept, if available.
- Relevant operating system, dependency versions, and device configuration.

Remove credentials, personal information, and confidential data from logs and examples before submitting them.

## Non-Security Issues

For installation questions, ordinary bugs, and feature requests, use the repository's [GitHub issues](https://github.com/NVlabs/GR00T-DataHardwarePrototypes/issues).
