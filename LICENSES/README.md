# License texts

The root [LICENSE](../LICENSE) contains the complete Apache 2.0 text.
[NOTICE](../NOTICE) lists the software it covers: the UMI and DexUMI
data-collection software, the GEAR Neck control software, the UMI gripper
firmware, the DexUMI hand monitor and the tools that install them.
The two Record3D-derived iPhone adapters, including NVIDIA adaptations,
are LGPL-2.1-only exceptions to that Apache-2.0 scope. Hardware designs and
documentation (websites and media) are licensed separately, under the
Creative Commons Attribution 4.0 International license in
[CC-BY-4.0.txt](CC-BY-4.0.txt).

Third-party license texts for that software are grouped by project:

| Collection | Coverage |
| --- | --- |
| [GEAR_UMI/](GEAR_UMI/README.md) | UMI software, gripper firmware source and the components linked into a built firmware binary. |
| [DexUMI/](DexUMI/README.md) | DexUMI hand-monitor notices, the vendor's MIT license for the X Hand URDFs and the license texts of the Python dependencies that the DexUMI software added; shared texts are reused from GEAR_UMI/. |
| [Record3D/](Record3D/README.md) | LGPL-2.1-only iPhone adapters in both pipelines, upstream attribution, a package replacement note and source release scope; reuses the retained LGPL text in DexUMI/. |
| [python-dependencies.md](python-dependencies.md) | Every third-party Python package pinned by the root `uv.lock`, with its declared license. Generated by `python3 tools/licenses.py deps`. |

[NOTICE](../NOTICE) identifies the applicable components, versions and text
paths. Third-party files retain their original copyright and license terms.
The earlier UMI MIT reference notice is retained for source/release provenance;
it is not an alternative license for the current software.

Include the root license and all applicable component notices when packaging
the software or firmware separately. One project license does not eliminate
required third-party license texts. `python3 tools/licenses.py check` verifies
source headers, the paths named in NOTICE, the dependency list and the license
files inside download archives. It also verifies the Record3D adapter
notices and rejects common bundled runtime artifacts in tracked paths and
ZIP/TAR member names. This submission distributes software source only;
installed dependencies and environments are obtained separately by users.
